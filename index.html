ℹ️ How to update / use this compliance page
Download Amazon reports weekly
Download the latest UK and US Seller Central reports each week so inventory, listing status and compliance records stay current.
UK reports: sellercentral.amazon.co.uk/listing/reports
USA reports: sellercentral.amazon.com/listing/reports
Choose: Amazon-fulfilled Inventory Report for current FBA sellable / unsellable stock. For the USA, also download All Listings Report so ASINs, SKUs and Active / Inactive listing status can be reconciled.
Then upload the downloaded report files to ChatGPT. Ask ChatGPT to check the latest UK/US Amazon inventory and compliance information and update Box Packer. ChatGPT can compare the reports with this page, flag anything unusual, update the dashboard and change the Last updated date.
How the compliance information is built: this is a working record compiled from Amazon compliance emails, Paul's compliance spreadsheet, Intertek/testing correspondence, and periodic Seller Central reports. The latest Seller Central compliance page and newest provider email should always be treated as the final live check if anything conflicts.
